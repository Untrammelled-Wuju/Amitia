Native Driver 状态说明

Native Agent/Helper 必须在 manifest 的 nativeCompanions 中显式声明并通过 SHA256 校验。Windows 使用受管 Weixin.exe；Linux 优先使用官方 Linux 微信 + LD_PRELOAD Helper。未知微信版本不会调用未验证的内部偏移，直接 fail-closed。
