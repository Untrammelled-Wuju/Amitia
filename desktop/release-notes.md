更新日志

26.2.0-beta.14

本次更新重点提升桌面端与 Android 端的更新下载效率，新增多线程分段传输、断点续传和完整性校验，并进一步改善应用退出、长期连接处理与 Android 兼容稳定性。

## 多线程更新下载

- 桌面端与 Android 端更新下载支持多线程分段传输，大文件更新速度更快。
- 根据服务器能力和网络类型自动调整下载策略，避免固定占用过高带宽。
- 服务器支持 Range 时启用断点续传，网络中断或应用重开后可从已完成分片继续。
- 下载完成后自动校验文件大小与 SHA-256/SHA-512，确保更新包完整可信。
- 服务器不支持分片或并行下载异常时自动回退单线程，保证更新仍可完成。
- Android 根据 Wi-Fi、蜂窝网络和以太网环境动态调整并发数，并在通知栏显示下载进度。

## 稳定性修复

- 修复应用退出时长期事件连接未及时结束、导致关闭等待超时的问题。
- 修复运行时关闭期间调度任务重新拉起后台服务的问题，退出后不再残留核心或数据库进程。
- 优化桌面端等待核心服务退出的流程，确保 Qdrant、SurrealDB 和应用核心按序结束。
- macOS 自动跳过当前更新通道不支持的桌面自更新检查，避免无效报错。
- 修复 Android 7/8 上部分无障碍动作调用高版本接口的兼容问题。

## 适用范围

- Windows 桌面端自动更新
- Android arm64-v8a 正式客户端
