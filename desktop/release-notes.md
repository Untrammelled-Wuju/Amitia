# 更新日志

26.2.0-beta.17

本次更新重点优化手机端记忆管理与页面切换，完善 QQ 个人号接入，并调整渠道设置、消息展示和桌面弹窗体验。

## 更新内容

### 记忆管理更集中

- 手机端记忆总览改为搜索与筛选页面，移除重复的记忆工具卡片入口，集中提供新增记忆、生成候选、待审核候选和刷新操作。
- 手机端记忆列表、对话记忆上下文与备份计数统一使用设备归属数据通道；角色详情中的「记忆」页签可直接查看和管理该角色的记忆。
- 修复桌面端与手机端在「全部记忆」范围下，误拒绝同一设备其他角色记忆的问题，并按条目实际归属执行后续操作。
- 手机端用户画像读取与新增接入统一归属通道，完善分类、关键词筛选和分页，优化画像属性与记忆标题的可读性。

### 导航与页面切换

- 桌面端「用户画像」入口移至「记忆」分区；手机端「我的 → 角色」新增二级页，统一进入「角色管理」和「世界书」，世界书从记忆中心移出。
- 手机端二级页面统一采用 320ms 等距横向滑动，前后页面同步进出；底部主标签切换保持即时响应，并适配系统减少动画设置。
- Android 关闭预测式返回，使用系统返回完成页面切换，减少系统返回动画与应用转场叠加。

### QQ 个人号接入

- QQ 个人号插件改为围绕 SnowLuma 配置接入，桌面工作区提供 SnowLuma WebUI 与 noVNC 桌面标签页。
- 新增容器名、WebUI 与 noVNC 端口、Docker 路径配置；支持读取并复制可用登录信息，修改、加密记录或清除 WebUI 密码。
- 完善 QQ 群聊与私聊名称解析，补充发送者、@ 提及及引用摘要信息传递；桌面渠道消息页增加群聊 / 私聊统计和媒体类型标识。
- QQ 语音合成改用校验渠道身份的专用接口，补齐文件地址与文件名向核心服务的传递。

### 渠道管理与消息整理

- 桌面端与 Web 渠道工作区新增「设置」标签，可配置沙箱隔离与联网开关，并将受约束的文件访问和命令执行限定到渠道沙箱。
- 桌面端与手机端普通对话列表过滤渠道会话，渠道消息集中在对应渠道入口查看；微信渠道的新入站消息统一进入单会话视图。
- 优化桌面渠道消息列表、插件标签页与消息区域的滚动布局。

### 桌面弹窗与窗口布局

- 调整标题栏与内容区布局，优化聊天标题挂载时机，修正自定义背景和内容区的高度衔接。
- 弹窗、抽屉和搜索浮层打开时阻止标题栏交互与拖拽，统一遮罩层级；普通弹窗居中显示，长内容在弹窗内部滚动。

## 适用范围

### 更新通道

- 桌面端与 Web：记忆归属修复、导航分组、渠道设置、消息展示与弹窗布局。
- Android：记忆管理、角色与世界书入口、页面转场及渠道会话过滤。
- QQ 个人号插件：SnowLuma 接入、登录信息管理与渠道消息增强。

## 使用说明

- SnowLuma 相关功能需要可访问的 Docker 与 SnowLuma 环境；内嵌 WebUI、noVNC 标签页限桌面客户端。
- 渠道隔离需运行平台支持；修改后应重启对应插件，插件进程才会按新策略启动。
- 本公告依据 beta.16 已发布源码与当前源码差异整理；beta.17 安装包及正式发布状态以实际发布为准。
