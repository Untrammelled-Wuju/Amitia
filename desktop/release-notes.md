# 更新日志

26.2.0-beta.21

本次更新完整对比 `26.2.0-beta.20` 源码基线 `7fb42386` 与当前 `beta.21` 发布源码，覆盖全部 198 个文件，其中 162 个修改文件、36 个新增文件；文本差异新增 14,379 行、删除 3,333 行，共 1,386 个差异片段，另包含 1 个 macOS 图标二进制文件。公告内容已按提交、文件、差异片段和用户可见行为逐项核对。

## 更新内容

### 长期记忆与召回

- 长期语义记忆与情节记忆改用不同衰减策略：事实、画像、偏好、习惯、计划和关系长期保留，长期未使用时降低召回权重并进入休眠；情节记忆可按原有规则自动归档。
- 休眠和自动归档仍保留原始内容、来源与版本，可通过明确记忆检索读取并恢复；普通聊天只使用活跃和淡化记录，手动归档、停用、到期和删除不会被自动恢复。
- 记住 `validFromUtc`、`validToUtc`、`expiresAt`、停用和归档状态，尚未生效或已经失效的记录不会进入普通上下文。
- 召回评分改为综合语义、关键词、重要性、置信度、生命周期强度、新鲜度、来源验证、强化次数、历史效用和时效，不再只依赖单一强度。
- 相同角色或全局范围内的同层同键记录只保留最高分结果，避免重复副本挤占上下文；桌面端与手机端均可查看召回总分和各项评分依据。
- 只有本轮实际召回且版本仍有效的记忆会增加强化、检索、注入和使用计数，写入、提取和重试不会无条件强化未使用的记忆。
- 新增“召回有用”和“召回无用”反馈。系统保存当次召回特征，并按角色独立更新语义、关键词、重要度、置信度、强度、新鲜度、验证、强化、效用和时效权重。
- 每条记忆独立维护稳定度、难度、召回概率和下次复习时间；反馈会调整个性化半衰期，固定记忆仍保持最高强度。
- 新增记忆确认、争议和更正流程。更正正文会保存原内容哈希、更正原因、更正时间与来源，并标记为用户已更正；确认正确会恢复置信度和上下文使用，标记有误会降低置信度并停止普通对话使用。
- 每次修改记忆前保存不可变历史快照，最多保留最近 20 个版本；桌面端和手机端均可查看历史并恢复指定版本。
- 新增记忆巩固检查，扫描重复内容、同键冲突、聚类摘要、争议、失效和高价值低召回概率记录，并给出复习建议。
- 后台巩固任务首次延迟 2 分钟、之后每 30 分钟按角色运行；仅对自动提取、未确认、未固定、正文完全相同的低风险重复执行软归并，保留原记录并记录归并目标和时间。
- 聊天上下文中的记忆集合增加 24 条、6000 token 预算和去重选择，避免过长或重复记忆占用模型空间。
- 桌面端与手机端统一展示活跃、淡化、休眠、自动归档、待确认、已确认、用户已更正和有争议状态，并新增休眠筛选、恢复召回、确认正确、标记有误、召回反馈、历史版本和巩固检查操作。

### 工作区与内置浏览器

- 修复 Chromium 命名管道通信，改为正确的 NUL 消息分帧和双向管道方向，避免请求粘包、阻塞和进程退出后残留注册。
- Chromium 连接或附加会话失败时保留底层错误，并在启动失败时注销托管进程、清理临时配置和运行状态。
- DOM 快照改为递归转换完整节点树，不再只保留两层；导航、刷新、后退和前进后会同步更新标签 URL、标题与文档代次。
- 前进和后退增加页面身份轮询与 CDP 会话重挂载，返回实际最终地址和标题，减少历史导航后页面状态空白或标签信息过期。
- 桌面工作区按钮、标签页和固定状态统一使用 Amitia 图标；标签支持中键关闭和右键固定、关闭、关闭其他、关闭右侧、关闭未固定标签。
- 工作区刷新会重新检查挂载目录，已移除的工作区会清空文件和 Git 状态，避免继续读取失效目录；文件列表同时兼容新旧 JSON 字段。
- 手机工作区重做为紧凑顶部栏和标签条，新增底部“打开工作区”面板，明确提供文件、Git、浏览器、终端和任务入口。
- 手机标签支持长按菜单、固定、关闭、关闭其他和关闭未固定标签，并修复 360、390、768 像素宽度下的布局溢出。
- 手机工作区支持从聊天内半屏打开，并可进入全屏页面；嵌入式文件浏览和 Git 页面不再渲染重复 AppBar。
- 手机文件浏览器增加返回目录、工作区切换、下拉刷新、紧凑文件列表、文件大小和修改时间展示；Git 工作区保留变更、Diff、分支、远程、提交、Worktree、检查点、测试与合并审计能力。
- 手机 WebView 浏览器默认使用可合法启动的 HTTP(S) 地址，禁止非 HTTP(S) 导航；远程 Chromium 继续提供实时截图、DOM、控制租约、前进后退、刷新和输入。
- 手机终端重做布局，增加工作区选择、运行状态、退出码、运行事件、任务历史、命令输入、发送、Ctrl+C 和安全区适配。
- 手机文档与 Diff 视图统一应用背景、边框和排版，保留刷新、加载下一部分和原始错误展示。
- 配置新增 `providers.browser`，可控制启用状态、Chromium 路径、无头模式、用户数据目录、启动与关闭超时、内存上限、允许协议、会话与标签数量、导航超时。

### 扩展中心单轨

- 修复 `/extensions` 路由仍指向占位页的问题，扩展中心现在真实挂载 `ExtensionCenterView.vue`。
- 扩展列表、状态、更新、信任、权限风险和诊断统一使用 `/api/extension-center/view`，详情统一使用 `/api/extension-center/extension`。
- 新增已安装、可更新、需要处理、本地导入、开发模式、发现六类视图及数量汇总；加载不完整时返回 `partial` 和具体诊断，不再静默显示空列表。
- 扩展卡片新增发布者、信任级别、最新版本、可回滚状态、系统管理、来源、开发模式、缺失权限、卡片动作和诊断字段。
- 扩展详情聚合模块、贡献点、权限风险、运行实例、版本历史、签名状态、更新状态、更新错误和可用操作。
- 更新检查增加 15 秒总超时和最多 4 路并发，系统管理扩展与正在安装、更新的扩展会跳过；失败原因写入卡片诊断。
- 启用、停用、权限修改、安装、更新和操作完成都会使扩展中心及详情缓存失效，切换页面后读取到最新状态。
- 桌面扩展中心和扩展包页、手机扩展中心和扩展包页均改为消费统一扩展中心数据；从扩展卡片进入更新或权限页面时会携带目标扩展和动作。
- 扩展中心和扩展包页补充更新版本、信任级别、权限风险、运行状态与详情字段，扩展中心详情保留版本历史，并修复详情字段与权限字段命名不一致导致的空白。
- 移除旧的 Kernel 扩展列表/详情接口、旧扩展包状态/列表接口和客户端兼容调用；扩展中心现在只有一套权威读模型。
- 本地设备与远端 Core 均注册同一扩展中心路由，客户端路由前缀补充扩展中心、扩展包、更新和版本接口。

### 扩展包更新与数据迁移

- 扩展包更新预览现在展示迁移路径、风险等级、确认项和迁移计划校验值，用户确认扩展包时同时确认经过验证的数据迁移计划。
- 手机端安装或更新扩展包后会等待真实操作完成，不再在只拿到操作 ID 时提前报告成功；失败对话框保留完整操作数据、响应内容和原始堆栈。
- 扩展包操作记录与每一步骤新增 `errorDetail`，升级、迁移、切换 Generation 和激活失败时可以查看原始错误链。
- 更新流程在执行迁移前先停止正在运行的旧扩展 Generation，避免迁移期间继续读写；失败补偿会按原启用状态恢复扩展。
- 迁移脚本执行前先校验数据库前置条件，条件失败时不会写入目标表；配置、资源、用户数据和 SQL 迁移均保留真实脚本错误与补偿错误。
- SQL、配置、资源和用户数据迁移支持补偿逆序执行；不可逆迁移、已完成但尚未验证反向数据恢复的迁移，以及部分成功的迁移都会进入人工恢复，不再自动回退。
- 迁移执行不再允许绕过扩展包。独立迁移、旧回滚执行、旧回滚恢复和旧恢复执行接口统一返回 `409` 及明确的扩展包上下文要求。
- 桌面迁移中心与手机迁移页只保留计划预览、Journal、快照和恢复扫描；执行迁移、版本回滚与恢复操作统一跳转扩展包页面完成。
- 启动阶段不再自动执行旧恢复动作；历史恢复记录仅用于人工核验，避免在缺少扩展包快照和真实数据逆序上下文时破坏数据。

### 更新与安装体验

- 桌面更新弹窗改为完整公告页，展示当前与最新版本、发布日期、安装包大小、更新通道、本版标题、最多 8 条亮点和 Markdown 完整更新内容。
- 桌面下载弹窗关闭后仍继续后台下载，完成后再次提示确认安装；“稍后提醒”只关闭本次弹窗，“跳过此版本”会持久化并停止提示同一版本。
- 桌面启动更新检查延迟到主界面成功显示 1 秒后执行，避免启动阶段弹窗抢占页面或干扰初始化。
- 手机更新提示改为 90% 高度底部面板，展示发布时间、安装包大小、通道、版本路线、本版亮点和 Markdown 完整更新内容。
- 手机可关闭弹窗让下载在后台继续，下载完成后显示独立安装确认框；强制更新版本不能绕过，下载或安装失败会展示原始错误。
- 桌面端与 Android 发布清单新增 `updateTitle`、`highlights` 和完整 `releaseNotes`，旧清单缺少这些字段时继续使用兼容回退内容。
- Android 保留仅由构建配置显式开启的 HTTP 更新源测试能力，正式构建默认仍只允许 HTTPS。

### 日志与诊断

- 后端日志改为按日期和单文件 50 MiB 双条件轮转，默认保留 30 天；手动轮转使用当前日志写入器并返回实际文件路径。
- 日志读取、清除、模型错误清理、提示词追踪和用户反馈诊断均可识别 `.log.1` 等轮转文件，同时拒绝无关文件。
- 桌面 Electron 主日志、桌宠日志和更新日志使用相同的按日/按大小轮转规则，关闭应用时会正确释放文件句柄。
- Android Runtime、iOS Runtime Bridge 新增本地轮转日志；Android 日志事件切回主线程发送，iOS 捕获 Host 标准输出、标准错误、启动失败和停止事件。
- 桌面与手机“最近日志”改为单页等宽原文视图，按文件显示 `==> 文件名 <==` 分组，默认最多读取 200 行，并保留轮转文件名。
- 日志 API 新增 1 到 200 的 `limit` 参数，非法值返回原始解析错误，不再静默套用固定值。
- 日志初始化、目录创建、过期清理、写入和关闭失败均向上保留原始错误；后端启动阶段无法初始化日志时会明确失败退出。
- SQLite 备份与快照校验修复 Windows 盘符路径 URI 编码，工作区列表响应固定使用 `entries`、`nextCursor`、`hasMore` JSON 字段。

### 桌面交互与安装

- 通用右键菜单新增首项自动聚焦、方向键循环、Home/End、Enter/空格执行、子菜单左右导航和分层 Esc 退出。
- 右键菜单增加单键访问键和读屏快捷键描述，Mac 上自动显示 ⌘、⇧、⌥ 等符号；项目、工作区和批量操作会根据可用命令生成动态访问键。
- 关闭右键菜单后恢复原焦点，窗口失焦、滚轮、缩放或内容变化会关闭菜单；聊天输入不再把右键菜单误判为模态框。
- Windows 卸载程序新增“同时删除 AmitiaData 使用数据”的可选项，默认保留数据；删除失败会显示路径、Windows 错误码和重启后继续删除提示。
- macOS 使用新的 Amitia 图标，并在已打包应用中支持 F12 打开开发者工具。

### 移动端与运行时可靠性

- Android Runtime 状态与日志事件统一在主线程投递，避免 EventChannel 跨线程异常；错误事件同时保留异常对象、消息和完整堆栈。
- Android Runtime 日志桥不再为每个监听器重复订阅，取消监听时释放 Sink；文件日志初始化或写入失败会记录原始错误并继续控制台诊断。
- iOS Runtime 写入持久化轮转日志，并对标准输出、标准错误、启动失败、停止原因和关闭失败进行可追踪记录。
- 手机聊天工作区底部面板高度提升到 92%，支持全屏二次展开并保持安全区、标签和当前页面状态。

### 兼容性与可靠性说明

- 旧 `/api/extensions/kernel/extensions`、`/api/extensions/kernel/extension`、`/api/extensions/packages/status`、`/api/extensions/packages` 读接口已删除，调用方必须迁移到扩展中心统一接口。
- 独立迁移、旧回滚执行/恢复和旧恢复执行接口不再提供独立写入能力，必须通过扩展包更新或版本回滚流程携带验证后的迁移计划和回执。
- 新增的休眠状态、确认状态、评分明细、巩固报告、历史版本、扩展卡片动作和诊断字段均为向后兼容字段；旧记录的衰减策略会按记忆种类和类型自动推断。
- 新日志文件采用带日期和序号的名称；旧 `.log`、`.log.old`、`.log.N` 仍可读取，并按 30 天保留策略处理。
- 新版本包含桌面、Web、后端和 Android 的跨端接口调整，建议升级后重启完整应用，使后端读模型、移动 Runtime 和桌面日志句柄同时更新。

## 适用范围

Windows、macOS 与 Linux 桌面端、Web 客户端、Android arm64-v8a，以及本地 Core、统筹 Core、设备归属和远端 Owner 模式；同时包含 iOS Runtime Bridge 源码更新，实际发布范围以对应平台构建产物为准。
