Amitia 26.1.4

解决侧车拉起缺失依赖

安装包内置 Node.js v22.12.0 便携版（Windows x64 / Linux x64），安装后无需系统安装 Node.js 即可运行微信/QQ 侧车。侧车首次启动时自动从压缩包解压 node.exe/node，无额外操作。

端口调整

Qdrant、SurrealDB、微信侧车、QQ 侧车端口统一前移，避免与常见开发端口冲突：
- Qdrant: 6333 → 16333，gRPC: 6334 → 16334
- SurrealDB: 8000 → 18000
- 微信侧车: 9876 → 19876
- QQ 侧车: 9877 → 19877
- AmitiaCore: 8899 → 18899

主动消息系统完善

- 主动消息（早安分享等）改为走完整角色模拟管线，与对话回复风格统一
- 时间感知、心理状态等上下文系统接入主动消息管线
- 修复主动消息在 SSE 中泄露为"用户消息"的问题
