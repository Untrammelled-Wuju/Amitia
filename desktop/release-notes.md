更新日志

26.2.0-beta.16

本次更新围绕多角色协作、插件工作区形态、设备归属与运行权限三条主线展开：新增群聊让多个角色在同一会话内分别作答，插件界面改为标签页并支持嵌入外部网页，记忆、任务与多智能体调度的权限和边界进一步收敛到当前设备与当前角色。

## 群聊与多角色协作

- 桌面端和手机端均可新建群聊，把多个角色放进同一会话，单个群聊最多支持 8 个角色。
- 群聊内每个角色独立成条回复，带自己的头像与名字，不会互相冒用身份发言。
- 输入框上方提供 @ 成员快捷条，包含「@所有成员」，被点名的角色会依次接话。
- 群成员面板可重命名群聊、邀请或移除角色，并可开关「允许角色互相 @」，让角色在回复后主动邀请另一位成员继续。
- 成员面板会显示每个成员可见的历史范围，并可决定新成员能否看到加入前的对话。
- 桌面端成员面板提供失败成员列表与重试按钮，可让回复失败的成员单独重新生成。
- 群聊支持「让 TA 回复」指定最近一条消息。

## 插件工作区与界面形态

- 插件工作区改为标签页组织，渠道插件页与消息统计等并列成标签，切换标签时保留各自状态。
- 插件可以注册自己的工作区标签页，并通过路由前缀和上下文条件决定何时出现。
- 桌面端插件可嵌入外部网页，支持前进、后退、刷新、在浏览器中打开以及清除站点数据（含登录状态）。
- 新增插件工作区侧边栏槽位，插件可在自己的页面左侧渲染导航项。
- 插件界面新增图片节点渲染，图片可点击放大，资源通过带鉴权的插件接口读取。
- 原先的受限与隔离两类沙箱网页界面下线，插件页面统一改为在客户端内以同页模块加载。
- 插件 SDK 新增工作区标签页、工作区侧边栏与宿主访问声明，并要求网页模块声明内容与样式哈希。

## 表情插件

- 桌面端表情包页重构为「表情 / 分组 / AI 设置」三个标签，支持按名称、含义和关键词搜索并显示数量统计。
- 手机端补齐独立的表情页面与侧边栏布局，可直接管理表情、分组与 AI 设置。
- AI 表情改为由模型自主挑选后发送，用户可控制总开关、每小时发送上限和同表情冷却时间。
- 插件界面增强弹窗区块、工具栏行、外部联动标签页、图库搜索过滤、必填校验提示与站内链接跳转。

## 渠道接入与媒体消息

- 新增 QQ 个人号渠道，通过 OneBot 11 反向 WebSocket 接入 NapCat，插件页可配置连接地址与 WebUI 登录令牌。
- QQ 渠道支持图片、视频、语音和文件的收发，语音可由 TTS 合成后回发。
- 群聊触发方式可选「全部消息」「仅 @我」或触发词前缀，并可忽略指定用户。
- 原 QQ 渠道更名为 qq-clawbot 以区分两者。
- HTTP 渠道插件新增视频与文件投递能力，外部渠道消息按渠道配置解析会话归属，不再落到默认会话。

## 记忆与数据归属

- 记忆归属收敛到当前设备与当前角色，取消角色级「全局记忆」开关，升级时自动清理旧开关字段与跨分区迁移记录。
- 用户级全局记忆范围仍然保留，可在记忆页查看范围中切换，条目也能在全局与角色之间升降级。
- 记忆页筛选条常驻显示，刷新按钮与图谱迁移选择器上移到内容上方。
- 记忆候选审核通过后可追溯来源对话与被替换记忆的版本。
- 备份、恢复与迁移的权限校验与设备归属保持一致。

## 角色与头像

- 角色头像在桌面端、手机端、跨设备与云端场景下正确显示。
- 消息列表与会话搜索结果按角色关联头像，兼容旧对话与已停用角色，缺失头像时回退为角色图标。
- 手机端支持自定义占位图。
- 角色编辑页按角色隔离用户画像，助手仅在明确要求时才写入全局记忆分区。

## 设备配对与运行模式

- 设置新增设备配对，支持扫码配对、手动配对与生成一次性配对二维码。
- 新增已绑定设备面板，可批准配对请求、授权能力、设置管理员、移除设备并刷新同步状态。
- 运行模式更名为「本地模式 / 云端统筹模式」，切换到云端前必须先完成配对。
- 「我的空间」合并为资料与身份信息页，并入设备与运行模式相关入口，同时展示 Space、Instance、Device、Runtime 四个标识。

## 导航与工作区

- 侧边栏改为分区式入口，包含角色、记忆、持续事项、扩展中心与渠道接入，固定为图标形态，悬浮显示名称与简介。
- 角色、记忆、创意工坊与扩展中心改为分区页加二级入口的层级结构。
- 置顶、最近与项目列表从第一栏移至第二栏，可拖拽调整宽度，「新对话」位于第二栏顶部并新增「新建群聊」。
- 逻辑项目支持无文件夹项目、不同项目复用同一文件夹、子工作区增删与主工作区切换，会话可手动移入或移出项目。
- 渠道消息页升级为「渠道接入」中心，可直达各渠道插件。
- 手机端改为底部标签栏，划分为消息、任务、记忆、插件与我的，并新增记忆中心与我的中心。

## 长期任务与持续事项

- 长期运行维护统一为单一权威来源，桌面端和手机端展示真实任务状态、执行位置与活动任务数量。
- 最大并发任务数可设为 1 至 20，统一超时可设为 30 至 1800 秒并支持禁用，旧设置自动迁移。
- 保存配置需由执行器确认生效，切换 Core、设备模式或管理员权限后旧页面操作会被拒绝，他端改动会提示重载而不是静默覆盖。
- 清理临时文件、轮转日志与数据库完整性检查加入 Core 与权限校验，Core 变化时提示重载。
- 同一任务不再同时归属两个持续事项，出现冲突时停止自动迁移并保留原记录供人工核对。
- 设备端任务账本支持只读查询，可查看某次设备任务是否执行、执行到哪一步并取回结果。

## 多智能体与预算

- 多智能体委派新增子任务依赖、截止时间、工具调用上限以及总 Token 与成本上限。
- 推理模型表单新增预算计价版本与输入、输出计价上界，未配置时受成本限制的委派不会调用模型。
- 父任务取消后子任务约 0.2 秒内停止并标记为已中断，父委派预算变更后尚未开始的子任务不再执行。

## 聊天回复与反馈

- 回复阶段跨端同步，思考结束与正文输出完成会在两端同时体现，思考块与正文完成后不再保留加载态。
- 正文已生成但尚未保存时显示「正在确认保存…」，避免出现空消息或重复消息。
- 反馈按钮只在回复已保存后出现，提交与撤销带归属校验，不会串到其他消息，归属变化时会提示重新操作。
- 实时通道断流后自动重连并按快照重建对话，被中断但服务端已保存的回复会恢复为已完成状态。

## 桌宠

- 桌宠中心收敛为安装管理入口，保留安装、启用停用、升级、调整大小与运行配置。
- 桌宠云端图片生成桥接以及制作记录、处理复核与动作编辑入口下线。

## 稳定性与兼容性

- 对话流文件存储加入文件锁与事件序号连续性校验，序号不连续时服务端下发快照重建请求，重启或多进程运行都不会丢消息。
- 任务维护接口统一迁至新的运行时任务路径，旧路径不再提供服务，相关旧客户端需要与本版本同步升级。
- 桌面标题栏在所有平台统一渲染，移除多余的二级工作区容器。
- 本版本涉及的旧扩展接口与旧插件页面形态不再提供兼容回退，插件作者需要按新的槽位契约适配。

## 适用范围

- Windows、macOS 和 Linux 桌面端
- Web 客户端
- Android arm64-v8a 正式客户端
- 本地 Core、云端统筹 Core 与设备代理模式

- 本次升级自动执行数据与结构迁移，不需要手工重写数据库；涉及群聊、插件工作区、记忆归属、设备配对、任务维护和桌宠的旧客户端应升级后再继续使用。
