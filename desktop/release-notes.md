# 更新日志

26.2.0-beta.22

## 更新内容

### 角色、团队与子智能体

- 角色团队成为唯一协作入口：同一份角色档案同时服务普通对话、群聊和团队协作，不再维护另一套独立的 Agent OS 角色管理面。
- 团队支持模板创建、负责人和成员、共享上下文、共享工作区、按明确提及或能力路由，以及任务交接的创建、接收和完成。
- 角色创建或更新会同步唯一 Agent 档案与版本；团队成员只能引用当前空间存在的角色，团队写入使用 revision 校验，防止并发覆盖。
- 新增子智能体工作台，按层级展示主对话智能体与子智能体的运行、角色、目标、状态、更新时间和消息记录。
- 运行状态覆盖规划、运行、等待、完成、失败、取消和暂停；消息区分指令、进度、问题、结果、错误与用户输入。
- 主对话可以创建、查看并向子智能体发送消息，子智能体可回报问题、进度和最终结果；消息按空间与运行标识隔离并持久化。
- Web、Electron 与 Android 使用同一角色、团队和子智能体主链；移动端同步提供团队入口、工作台视图和运行消息交互。
- 旧 Agent OS、角色电脑、评估与 A2A 管理入口没有作为第二套系统保留；最终能力分别归入角色团队、子智能体、插件、市场和现有业务模块。

### 可信执行、审批与注意力

- 工具执行统一经过权限策略、持久审批、副作用对账、资源租约、审计记录和模型使用计量，降低越权、重复执行和无法追踪的副作用。
- 审批、等待、失败恢复和可查看结果集中到“现在需要你处理”，支持本次批准或拒绝，并可打开完整决策时间线。
- 消息来源可按空间、渠道、账号、会话和发送者逐级配置；明确请求与推断请求分别支持允许执行、仅观察和拒绝。
- 新增每日打断上限、重复确认上限、连续追问上限、无变化通知上限和去重窗口，超出预算的提醒会被抑制并记录原因。
- 影子模式只记录本应抑制的提醒，不改变实际发送；界面展示今日打断、已抑制和影子观察数量，便于上线前校准策略。
- 主动任务创建增加并发幂等键，双击、重试和并发请求会复用同一任务；调度冲突时会等待并读取已存在的创建结果。
- 通知和主动任务保留原始失败原因；Temporal 参数、状态、limit 与周期规则增加严格校验，非法输入直接返回完整原始错误。
- 持续事项、失败恢复、代理运行和进程恢复增加定向回归测试，覆盖重复请求、重启恢复、错误传播和状态一致性。

### 插件市场与通用宿主协议

- 插件市场作为预装普通插件交付，提供插件目录、分类、详情、预览、安装、更新和卸载，不再以核心内置处理器伪造市场能力。
- 新增通用 `host.plugin.list`、`host.plugin.preview`、`host.plugin.install` 和 `host.plugin.uninstall` API，并由插件 SDK 暴露给第三方插件。
- 市场支持多个目录来源、发布者信息、官方信任、版本兼容、包校验、操作 ID、安装状态和动态 UI 槽位。
- 桌面端与手机端新增插件市场页面和卡片布局；安装、更新、卸载遵循统一扩展包生命周期，并把真实错误和操作状态返回界面。
- 内置插件启动时执行清单与同步校验，缺失或被移除的贡献点会按当前插件集合重新登记，避免启动后仍显示已删除入口。
- 预装插件签名改用可复现构建时间，重复构建得到一致签名和包哈希；同版本插件不会再因构建时间变化被判定为不同内容并阻断首次启动或旧数据升级。
- 数字身份能力拆分为邮箱、日历、手机号和钱包四个独立插件包，含运行时、签名、打包、上传、校验和插件测试，不进入核心程序。
- 扩展 Schema UI 增加动作确认、数据绑定、权限摘要、禁用态和错误展示，插件页面可通过同一渲染器接入桌面与移动端。
- MCP 请求参数解析失败时保留原始错误内容；插件安装、预览、调用、更新和卸载失败均向界面传播完整错误链。

### 角色模型、对话与世界书

- 每个角色可独立覆盖文本模型与思考参数；角色未配置时明确回退到默认模型，角色编辑页同步展示当前可用模型。
- 角色创建与编辑补充性别、模型和团队来源字段；旧角色记录不会生成兼容层，所有写接口只接受当前格式。
- 聊天错误提示区分用户可读说明与完整原始错误；可展开、复制错误对象、错误链、消息、详情和堆栈，不再只显示固定文案。
- 世界书新增本地导入、关键词高亮、分页读取和当前版本校验；修改与测试采用请求顺序保护，过期响应不会覆盖新数据。
- 世界书测试结果会在正文或配置变化后失效，避免旧结果继续显示；并发写入按角色和世界书版本隔离，防止请求串写。
- 对话日志、项目模式、角色切换、时间线和消息投影统一使用当前格式，修复切换角色后消息归属、工具摘要和错误详情错位。
- 移动端聊天输入、角色切换、消息渲染和错误面板同步更新，保持长期记忆、工具调用和团队成员身份在当前会话中的一致性。

### 生图能力与持久制品

- 新增 Stability 与阿里通义万相适配器，保留原有 Seedream；不同供应商通过统一能力声明描述参考图、多图、负向提示词、种子、异步任务与取消能力。
- 生图请求统一支持模式、提示词、负向提示词、参考图、宽高、种子、输出数量和幂等键；供应商不支持的字段会明确失败，不静默丢弃。
- Seedream 参考图增加数量、内容和大小限制；异步供应商支持提交、查询、轮询、取消、超时、限流和状态未知恢复。
- 生成结果写入持久 Artifact，并返回 `amitia://artifacts` 资源 URI；桌面与手机可直接预览、再次引用或继续用于角色与场景生成。
- 生图配置页与手机模型配置页增加生成测试、尺寸、参考图 URI、供应商模型提示和完整错误展示；API Key 仍只保存在本地服务端。
- 云端生图网关统一身份、供应商选择、错误映射和请求回执，避免云端与本地对同一模型得到不同错误或结果格式。

### Android 虚拟显示与移动交互

- Android 虚拟显示新增实时预览服务，可把隐藏 VirtualDisplay 画面以悬浮窗口连续显示，支持启动、停止、尺寸变化和生命周期回收。
- 新增预览几何与策略模块，处理画面缩放、位置、边界、触控坐标映射和不同屏幕密度，保证点击位置与可见画面一致。
- 虚拟显示设置页与调试入口展示能力状态、显示参数和运行控制；系统不支持时返回明确状态，不伪装成可用。
- Android 无障碍、通知、自动化、相机和原生桥接补充虚拟显示参数与错误传播，远程操作可复用同一显示和输入链路。
- 移动端提醒页扩展注意力预算、来源策略、决策时间和待处理事项；消息、输入、角色团队、市场和日志页面同步当前接口。
- iOS 原生 Host 对虚拟显示返回明确的不支持状态，不保留伪实现或平台兼容分支；其他 Runtime Bridge 能力继续共享当前协议。

### 跨端运行时、启动与就绪

- Android Runtime Package、Linux ARM64 后端、plugin-host 与 task-host 必须由同一份后端源码重新构建，发布包携带 sourceCommit 和组件哈希。
- Runtime 安装校验新增清单、执行权限、二进制哈希、启动探测和平台兼容检查；旧 Runtime Package 或旧后端产物不会被接受。
- Core 启动新增 health 与 readyz 就绪模型，区分 ready、degraded、blocking 和 failed；模型未配置等状态可在不影响服务启动时明确展示。
- 桌面 Core 进程、移动内嵌 Runtime 和云端设备执行统一监听端口、进程所有权、重启和终止逻辑，并增加端口占用与启动阶段测试。
- 设备待保存队列改用固定宽度的纳秒时间排序，修复整秒边界下已有记录被误判为尚未到期、后台投递和启动恢复偶发读取不到待处理数据的问题。
- 修复 macOS 临时目录在 `/var` 与 `/private/var` 规范化后被误判为 Task Host 文件树越界的问题，固定任务包和私有依赖现在可以正常校验并执行。
- 修复任务宿主拒绝归属错误的结果后未及时关闭输出管道、导致子进程退出等待卡死的问题；异常任务现在会立即失败并返回原始错误，不再拖住登录或功能加载。
- 运行时连接代次改为按历史最大值单调递增；关闭、崩溃或升级后的新会话不会再与旧会话占用同一代次，桌宠与扩展运行时不再陷入绑定冲突和无限重连。
- 移动端后端拓扑支持本地、云端、远程和混合模式；切换部署模式会重建业务连接并明确提示运行数据不随模式迁移。
- 桌面更新保留分段下载、后台下载、稍后提醒和跳过版本；Core、Qdrant、SurrealDB、渠道插件与 Runtime 资源按当前发布白名单装配。

### 界面、可访问性与工作台

- 侧栏分组名称简化为角色、工作、扩展和系统等直接标签，减少重复说明；桌面与手机保留一致入口层级和当前页面状态。
- 工作台新增子智能体入口，展示运行数量、活动子智能体和持久消息；文件、Git、浏览器、终端、任务与子智能体共用标签状态。
- 消息渲染补齐角色头像、身份标识、工具摘要、引用和错误卡片；长内容、代码块和 Artifact 在桌面与手机使用统一的预览与下载行为。
- 通用交互补强键盘导航、焦点恢复、右键菜单、屏幕阅读说明和窄屏布局；公告样式采用纯白、左对齐、紧凑间距。

### 聊天清理、备份与数据恢复

- 聊天清理前创建完整备份并执行恢复预览校验；备份无法完成或清单不可读时禁止删除，避免清理成功后才发现无法恢复。
- 备份先写入隐藏临时文件，完成同步、加密和哈希校验后再原子发布；中断或失败不会留下可被误识别为有效备份的半成品。
- 备份列表只展示格式有效、清单可读取且属于当前版本的备份；损坏包、旧格式包和无关文件直接失败并展示原始原因。
- 数据备份恢复覆盖角色、会话、消息、记忆、配置、附件和 Kernel 数据，并在恢复前后校验文件、数据库和资源引用。
- App DB 与 Kernel DB 的存储统计合并展示，覆盖全部角色的消息、会话、记忆、工具记录和附件，不再只统计单一数据库。
- 数据库完整性检查覆盖 SQLite `integrity_check` 与 `foreign_key_check`；发现损坏、孤立引用或约束失败时停止后续迁移并返回完整错误。
- 聊天记忆、资料备份、数据端点和设备归属恢复增加 requestId 幂等、状态查询、失败恢复和事务回滚，避免重复写入或部分成功。
- 记忆备份、消费游标、任务恢复、进程恢复、来源恢复和运行编排恢复增加 QA 回归，覆盖重启、并发、超时和损坏输入。

### 错误原文、校验与单版本边界

- 前后端统一原始错误提取，保留 error、message、msg、detail、internalMessage、reason、cause 与堆栈，不替换、截断或吞掉底层错误。
- 提醒、长期任务、手动操作、世界书、MCP、备份和恢复界面均可查看并复制完整原始错误，同时保留面向用户的解释与处理建议。
- Temporal 定义、触发、暂停、恢复和列表接口增加参数类型、范围、状态迁移、limit 与周期表达式校验，冲突返回明确错误。
- 主动任务、调度任务、世界书写入和备份恢复均使用幂等键或 revision；并发重试只产生一个有效结果，过期请求不会覆盖新状态。
- 删除旧迁移命令、迁移表、兼容字段、legacy 路由、双写/双读、旧插件包、旧 Runtime、旧协议、旧日志命名和回退端口。
- 旧输入不再自动转换、推断或修复；无法识别时必须原样失败并返回完整原始错误，客户端只支持与当前源码同时构建发布的协议。
- 新增源码错误、数据恢复、存储完整性、世界书并发、手动操作契约、Runtime 安装和发布门禁测试，避免修复只在个别页面生效。

## 适用范围

Windows、macOS 与 Linux 桌面端、Web 客户端、Android arm64-v8a，以及本地 Core、统筹 Core、设备归属和远端 Owner 模式。iOS 当前包含 Runtime Bridge 源码与明确的平台能力状态，实际发布范围以对应平台构建产物为准。

升级本版后应同时更新桌面端、Web、手机端、后端 Core、Runtime Package 与插件包；只更新其中一端时，旧协议、旧数据和旧运行包会按单版本策略直接失败。
