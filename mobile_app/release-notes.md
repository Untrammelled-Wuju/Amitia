更新日志

26.2.0-beta.15

## 更新内容

- 移除消息页搜索入口的边框、点击水波纹与高亮，保留搜索跳转。
- 统一设备所属记忆的入口、全局记忆范围与备份、恢复、迁移权限。
- 优化消息页顶栏和搜索区域间距，统一手机端页面导航与角色资料展示。
- 完善扩展工作区侧栏、表情插件跨端布局和 QQ 渠道媒体处理。
- 改善模型消息协议兼容与设备间消息、记忆数据交互。
- 统一聊天回复阶段、消息动作和反馈状态，减少跨端显示不一致。
- 长期任务维护读取真实执行状态，统一并发、超时配置与运行权限校验。
- 统一本地、云端统筹和设备代理的数据访问权限与当前 Core 配置入口。
- 同步工作台任务证据、预算、依赖和执行记录展示。
- 修复角色头像数据返回，完善角色和桌宠资源管理。
- 调整设置导航、扩展列表与跨端页面入口。

## 适用范围

- Android arm64-v8a 正式安装包，版本 26.2.0-beta.15，versionCode 21。
- 内置后端、插件宿主和任务宿主均从本次源码重新编译，并重新生成 Runtime Package。
- 本次为本地构建和真机覆盖安装，不发布更新通道。
