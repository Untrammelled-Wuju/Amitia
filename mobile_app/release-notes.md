# 更新日志

26.2.0-beta.20

本次更新完整对比 `26.2.0-beta.19` 已发布基线 `b4828ae4` 与 `beta.20` 发布源码，覆盖其间全部 34 个历史提交、1375 个文件和 6376 个差异片段，不是只比较 `beta.19` 最近一次 Android 重构建。

## 更新内容

### 本地模型管理与推理

- 新增本地模型库，支持导入、列表、检测、绑定、测试和删除 GGUF、MNN 模型文件。
- 接入 `llama.cpp b12018` 与 MNN 内嵌运行后端；模型配置不再要求 Base URL 和 API Key，改为展示运行环境可用状态与模型文件选择。
- 模型导入执行 32 GiB 上限、最小文件长度、GGUF/MNN 文件头、SHA-256 去重、原子落盘和空间归属校验，相同模型不会重复保存。
- 模型配置保存时校验被引用的模型文件、格式、MMProj 投影模型、上下文窗口和输出上限；仍被配置引用的模型文件禁止删除。
- 本地运行进程使用 Provider、配置指纹和模型标识生成稳定且限长的运行身份，避免不同模型或多个运行实例互相串用。
- 内嵌模型增加上下文预算：系统消息、最近消息和输出预留优先保留，超长历史按预算截断并附明确截断提示。
- 桌面端与手机端模型配置页均新增本地模型导入、文件选择、运行能力、不可用原因、真实加载探测和最小推理测试。
- 新增 `llama.cpp` 六平台运行库清单、SHA-256 校验、缓存下载、临时目录解压和运行清单生成，覆盖 Windows、macOS、Linux 与 Android arm64 所需输入。

### 知识检索单轨与诊断

- 知识检索意图识别、ACTIVE/LEGACY、SHADOW、Feature Gate 和降级原因收敛到后端统一路由解析器，聊天链路和客户端检索共用同一份有效策略。
- 自动检索明确使用 `routingMode=chat`，手动选择级别明确使用 `diagnostic`，客户端不再复制一套本地或云端路由判断。
- 搜索响应新增请求级别、实际级别、路由模式、策略模式、路由原因、影子级别、降级状态和降级原因，并保留证据充分度、冲突和时空信息。
- 桌面端与手机端检索结果同步展示聊天路由/诊断指定、请求到实际级别变化、Policy、Shadow、路由降级和 gate 原因。
- 手机端新增完整知识诊断页，接入运行时策略、索引 Outbox 健康、向量抽样、反向孤儿检查、分页巡检、页回执、二次核验、恢复审查、Trace、SLO 和 Benchmark。
- 手机端知识源详情补齐 Canonical Outline 分页、受限原文读取和恢复审查管理员权限版本；高级系统页新增设备身份校验。
- 知识接口的错误响应改为返回原始错误，索引、向量核验、孤儿检查、恢复审查和 Trace 失败不再被固定文案覆盖。

### 手机会话项目化与实时状态

- 手机消息页新增“消息/项目”双模式并持久化选择；项目模式支持创建项目、展开项目、项目内新建对话和项目内新建群聊。
- 项目可绑定本地目录或 Android SAF 目录，支持多个副工作区、主工作区切换、工作区移除、重命名、置顶、浏览和被移除项目恢复。
- 已有对话支持移入、移出或调整所属项目；新对话、新群聊按当前项目创建，并为运行时绑定对应工作区。
- 项目标题恢复为无卡片、无边距容器布局，项目空状态、无角色状态和消息空状态统一使用简洁页面层级。
- 会话运行时改为按草稿和会话隔离的管理器，多个对话可以独立保持生成状态；后台完成会更新未读数和活动摘要，不再互相覆盖。
- 会话列表实时展示思考、工具调用、任务、用户消息和 AI 回复的最新活动，仅在存在生成任务时每 2 秒刷新，减少空闲轮询。
- 修复新对话首次发送后的返回栈和草稿到正式会话的替换逻辑，避免返回时跳过消息列表或重新打开旧会话。
- 手机聊天页恢复键盘避让和项目布局，带查询参数的聊天路由被识别为聊天根页面，首次返回不再直接退出应用。

### 右键菜单、归档与批量操作

- 桌面端新增统一自定义右键菜单，支持位置和边界修正、左右展开子菜单、禁用状态、危险操作、Esc、点击外部、滚轮及窗口变化关闭。
- 通用右键菜单支持复制选中文字和链接、粘贴、打开/复制链接、保存/打开/复制图片地址以及切换深浅主题。
- 会话右键菜单整合打开、重命名、多选、置顶、标为已读、归档、移动到项目和删除；项目与分组右键菜单复用同一命令体系。
- 桌面消息侧边栏移除常驻行内操作按钮，降低误触并让完整操作集中在右键菜单；消息和项目中的会话可跨分组批量选择。
- 手机消息页和项目页新增批量选择、全选/取消全选、批量归档、已读、置顶、移动和删除；系统返回优先退出多选，再处理标签返回和双击退出。
- 归档页支持多选恢复与永久删除；失败项保留选中并展示完整原始错误，成功与失败可分别处理。
- 修复左右滑动操作结束后无法回弹、操作按钮与消息行移动不同步、多选时仍触发滑动和长按菜单位置固定的问题。
- 修复会话删除误用历史查询导致并发请求覆盖、后端确认成功后仍被轮询状态误报失败、重复删除已删除会话，以及主列表删除未携带角色的问题。
- 归档、恢复、单条删除和批量删除均携带会话角色；删除对话会清理消息、工作区关联和检查点，但保留记忆、事实、向量和图谱数据。

### 数据迁移单轨与敏感配置

- 下线旧 `/api/config/export`、`/api/config/import/preview` 和 `/api/config/import/confirm`，电脑端与手机端只保留统一数据可携带入口。
- 普通迁移可选择是否包含本地模型文件，并可选择携带模型 API Key、令牌等敏感配置；完整灾难恢复始终包含秘密。
- 选择敏感配置或完整备份时必须设置至少 8 位口令，并使用 `AMITIAE1` 加密格式；含秘密的明文旧包会被拒绝。
- 模型供应商配置对 `api_key`、token、password、secret、credential 等字段执行递归过滤，普通迁移预检明确提示目标设备需要重新授权或补填。
- 迁移包继续执行 ZIP 清单、SHA-256、组件数量、大小、冲突预检、事务导入和恢复前自动备份；本地模型资产作为可选组件单独归档。
- 本地、统筹 Core、远端 Owner 和物理灾难恢复分别沿用现有权威路由，不在客户端新增第二套迁移判断。

### 插件渠道与宿主可诊断性

- 插件宿主、任务宿主、RPC、网络策略、关闭流程、结果返回和 SDK 的捕获分支统一保留原始错误，不再用空捕获或固定信息覆盖。
- QQ Bot、QQ 个人号、微信、SnowLuma、表情插件及插件构建脚本的配置读写、网络、媒体、登录、安装、回滚和清理失败均保留原始原因。
- SnowLuma Docker 网络检查失败时会把底层错误附到回退警告，避免只剩“无法检查容器网络”的概括信息。
- 插件 CLI 校验错误、任务输出序列化和 RPC 消息解析均保留原始异常；SDK 日志不再把超过 4096 字符的错误文本截断。
- 新增面向前端、Dart、Go、Kotlin、Java 和 Swift 的错误处理审计器，检查空捕获、未使用错误参数、固定错误响应、无 cause 重抛和错误截断。

### 全链路原始错误

- 后端新增统一 `OriginalErrorMessage`，请求绑定或前置条件失败时保留原始错误；同时修复 46 个文件中原先可能对空 `err` 调用 `Error()` 引发二次空指针的问题。
- Web 新增原始错误提取器，优先合并响应 `data`、`message`、`msg`、`error`、`title`、`detail`、`internalMessage`、`reason` 和 `cause`。
- 手机端新增原始错误提取器，支持 `BackendTransportError` cause、Dio 响应体和嵌套 Map，界面错误可同时保留可读提示和完整服务端原文。
- 后端、前端、桌面、Android、iOS、插件、Runtime、任务宿主和构建脚本共 886 个差异文件包含原始错误传播改动；错误信息不再按状态码统一改写或截断。
- 当前源码执行错误处理审计，Web/Dart/桌面/插件结果为 `silent error handlers: 0`，Kotlin/Java/Swift 结果为 `silent native error handlers: 0`。

### 扩展入口与运行时稳定性

- 手机底栏“插件”统一更名为“扩展”，扩展中心标题同步修改，四块拼合扩展图标替换旧插头图标。
- 最终扩展图标保持 1.8 线宽和 21px 底栏尺寸，视觉边界收敛到 4.6–19.4，圆角为 1.55，三块方形模块与右下连接线组成统一光学大小。
- 移动端启动先完成 UI Runtime 快照加载再进入主界面；失效通知按版本号合并、补执行、去重，并在页面销毁时停止延迟回调。
- Proot 退出结果先写入退出引用并完成等待结果，再通知观察者；Runtime 替换不再被退出观察者阻塞，立即退出、自然退出、中断和异常四条路径统一只发布一次退出事件。

### 桌面端统一图标

- 新增 Amitia 统一图标组件，全部使用 24×24 画布、默认 1.8 描边、圆角端点和圆角连接，并支持继承父级字号缩放。
- 建立 104 个语义图形和 111 个 Element Plus 兼容导出，Web、桌面、类型检查与测试环境统一解析到同一图标模块。
- 侧边栏折叠、前进后退、窗口最小化/最大化/还原/关闭、搜索、主题切换、角色、渠道、记忆、持续事项、游戏、创意工坊、新建会话和归档会话图标全部统一。
- “扩展中心”和运行时缺省导航图标改为四模块扩展图标；语音模式键盘、语音播放波形和窗口按钮描边同步统一。

## 兼容与升级

- 旧配置导出/导入接口与两端旧入口已删除，后续迁移必须使用 `/api/data-portability/*`。
- 新版本包含新增接口与响应字段，但知识搜索的旧策略仍可作为受控 Feature Flag 兼容模式；手动指定检索级别进入诊断路由。
- 升级会保留现有聊天、角色、记忆、插件和设置；完整备份必须设置至少 8 位口令，普通迁移默认不包含 API Key 等秘密。
- 已导入的本地模型文件不会默认进入普通迁移包，需要在导出时显式勾选“包含已导入的本地模型文件”。
- 建议更新后重启完整应用，使桌面渲染资源、移动端 Runtime 退出顺序和本地模型运行库同时生效。
- 桌面端、Web、后端和 Android 版本已统一提升到 `26.2.0-beta.20`，Android versionCode 为 `26`。

## 适用范围

Windows、macOS 与 Linux 桌面端、Web 客户端、Android arm64-v8a，以及本地 Core、统筹 Core、设备归属和远端 Owner 模式。
