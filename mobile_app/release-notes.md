更新日志

26.2.0-beta.12

本次更新重点修复模型用途分配，优化对话上下文组织、模型用量统计与桌面窗口体验。

模型用途分配

- 支持分别为聊天、摘要和记忆提取分配模型，手机端新增用途分配入口。
- 修复已保存的用途配置未被实际调用的问题。聊天优先使用会话指定模型，未指定时使用用途模型，再使用默认模型。
- 会话标题、摘要和历史压缩使用摘要模型；自动记忆提取及记忆候选处理使用记忆提取模型。
- 修复修改单项配置影响其他用途的问题；删除模型后，关联用途自动恢复为默认。
- 完善云端配置权限校验，切换 Core 或撤销权限后，旧页面无法继续保存配置。

对话与模型调用优化

- 调整角色设定、历史消息与本轮上下文的排列，保持固定提示内容稳定，为支持提示缓存的模型提供更好的复用条件。
- 明确区分运行指令与记忆、知识库、世界书、引用等参考资料，强化上下文与工具授权边界。
- 接入模型返回的缓存 Token 数据，区分已缓存、未缓存及未报告用量，避免将未知数据误记为零命中。
- 完善流式响应用量解析，处理末尾数据缺少换行时的统计遗漏。
- 统一摘要压缩的模型调用链路，保留 Ollama 上下文和输出长度控制。

桌面体验

- macOS 与 Windows 使用系统原生窗口控制按钮。
- Windows 标题栏按钮颜色跟随应用主题。
- 全屏操作改用桌面窗口原生能力，同步全屏与最大化状态，完善标题栏空间适配。
