# 更新日志

26.2.0-beta.23

## 更新内容

- 底部「任务」使用与桌面端一致的日历图标。
- 普通对话、项目、搜索、归档和渠道对话按滚动分页，项目会话独立续页。
- 新对话立即显示「新对话」，发送和排队的引用保留完整内容，扩展加载异常保留原始报错。
- 更新 Android Runtime 的安装与替换校验，并完善插件能力绑定和对话执行记录。

- 设备协同与桌面端对齐：本机角色与统筹中心角色可切换，数据跟随所选角色的来源。
- 设备名称改为读取系统设置，不再由应用拼接设备标识。
- 设备能力按需暴露，未暴露的能力不会出现在远端的可用列表里，也不会被远端调用。
- 接入共享核心时以只读横幅常驻提示，保留后端返回的原始错误与堆栈。
- 消息发送改为排队执行，弱网、切后台或进程重启后未完成的消息会从检查点继续。
- 统一任务、记忆、扩展的导航图标，扩展页与设置页的间距一并调整。
- 修复连续对话中 AI 回复区域跳动、用户消息在生成期间错位的问题。
- 完善 DSH 扩展的工作区选择、会话准备、历史消息读取和助手状态展示，加载失败时展示宿主返回的原始错误与错误码。
- 新增证书固定校验，连接异常时保留原始校验失败原因。
- 新增运行时模式页与首次启动同意门，模式切换与授权状态以服务端返回为准。

## 适用范围

- 本版本仅支持当前版本的干净首次安装，不提供旧版本数据和运行时迁移。
