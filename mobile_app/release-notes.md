更新日志

26.2.0-beta.13

本次更新将主动任务收口为内置扩展，并将主动消息规则合并到统一任务工作台，同时修复生产环境路由、错误上报和跨平台发布资源问题。

主动任务

- 主动任务改为内置扩展，不依赖单独安装扩展包。
- 主动消息规则、频率、安静时段、随机延迟、每日上限、立即执行和执行历史已合并到主动任务工作台。
- 修复生产构建下角色主动任务入口 404 的问题，并兼容旧入口地址。
- 修复主动任务页面缺少角色上下文和 `characterId` 的问题。

反馈与诊断

- 用户反馈现在会同时收集 Electron 主进程、渲染进程和 Flutter 运行异常。
- 相同日志错误会按来源去重，避免重复错误占满诊断记录。
- 修复重复读取失败 WebSocket 导致核心进程退出的问题。

运行与发布

- 移动端继续使用同一份后端源码重新构建 Runtime Package 和嵌入式后端。
- 修复主动任务页面在部分生产运行环境中的兼容性问题。
