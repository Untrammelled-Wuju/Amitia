# Amitia Android 26.2.0-beta

- 新增侧边栏置顶、最近和项目分组，支持项目文件夹与项目内新建对话。
- 支持对话置顶、归档和撤销归档，归档对话可搜索、按项目筛选并查看完整聊天记录。
- 渠道消息调整为独立只读入口，不再混入最近对话。
- 新建对话改为发送消息后创建，并支持按会话和项目保存未发送草稿。
- 修复消息发送后可能消失的问题，用户消息会在后端处理前同步持久化。
- 新增 AI 生成状态提示，支持查看模型返回的思考内容。
- 优化侧边栏操作按钮、项目展开动画、空状态文案和桌面端归档页布局。
- 统一手机端侧边栏“新对话”入口与下方菜单项的字号。
- 重绘手机端项目分组中的“添加项目文件夹”图标。
