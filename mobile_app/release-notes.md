# 更新日志

26.2.0-beta.18

本次更新相较 beta.17 发布基线，集中升级安全决策、群聊容错、输入体验、执行过程、提醒事项、记忆隐私、QQ 个人号运行方式、桌面本地存储和本地数据恢复；旧联网研究链路正式下线，属于需要重点关注的不兼容变更。

## 重要变更

### 旧联网研究与搜索 API 退场

- 桌面端和手机端移除「搜索 API」设置入口、密钥管理和旧搜索服务调用。
- 删除内建 `web.run` / `web_run`、Brave、Exa、Tavily、Native Engine 和深度研究运行时。
- 删除网页引用、网页版本、证据、搜索引用和深度研究计划数据表。
- 升级迁移会安全清理旧搜索密钥引用，不删除聊天、知识库等无关数据。
- 浏览器自动化、知识库 `[K]` 引用和新执行过程保留。

## 更新内容

### BDI 安全策略

- 硬约束阻断会移除候选，优先会确定性提分置顶，原因同时写入禁止话题。
- 软偏好按候选或类别影响仲裁排序。
- 应对策略进入表达计划，支持问题时结合压力、情绪、认知负荷和关系支持度选择。
- 情绪表达支持表露、抑制、重构、内在强度、外在强度、负向情绪上限和亲密表达上限。
- 桌面端和手机端改为结构化编辑器，历史策略值自动迁移。
- 安全审计记录 BDI 版本、策略和最终情绪强度。

### 群聊协作

- 支持最多 8 个角色，拒绝默认角色自邀请、未知角色、禁用角色和越界人数。
- 重复成员、重复邀请、重复点名和重复请求均幂等处理。
- 群成员排序要求完整且唯一，重新邀请角色不会产生重复顺序。
- 群名按 Unicode 字符计数，中英文长度判断一致。
- 单成员失败显示明确原因并支持单独幂等重试。
- 手动停止会持久化为已取消，自动接话新增投递可在同一轮完成。
- 新成员可选择是否读取加入前历史。
- 回复流严格校验会话、轮次、投递、请求和执行身份，拒绝跨角色或跨轮次冒充。
- 心理、关系和需求状态按角色隔离。

### 输入与插件面板

- 桌面端和 Web 将上传、技能、群成员点名和插件输入扩展整合到统一命令面板。
- 上传入口合并为一个文件选择器，自动分流图片、视频和普通文件。
- Agent Skill 支持服务端搜索、分页和滚动加载更多。
- 群聊 `@` 支持所有成员、有效成员和名称重叠时的最长匹配。
- 手机端输入框改为双区卡片，集中回复引用、技能、附件、权限、工作区、推理强度和发送/停止。
- 手机端移除重复的文件、图片和视频中间面板。
- 插件输入面板复用统一浮层，支持 Esc、点击外部关闭和浮层互斥。
- 插件 Schema 新增分组画廊和紧凑贴纸画廊。

### 执行过程与错误

- 三端将「工具执行流」统一改名为「执行过程」。
- 工具名称转换为读取文件、修改文件、搜索内容、运行命令、操作浏览器、检索记忆等动作。
- 运行中每 250ms 更新耗时，完成、失败和中断后保留持续时间。
- 错误区分为超时、网络、上下文超限、工具循环、验证失败、浏览器不可用和用户停止。
- 相同工具、参数和错误连续失败 3 次时主动停止。
- 工具调用前的模型文字会作为可见进度展示。
- 结构化错误持久化，重连或重启后仍可查看。
- 群聊不再显示单聊角色切换分割线。

### 会话和本地凭据

- 后台刷新会话时保留旧消息，成功后再原子替换。
- 刷新失败保留当前内容并延迟 15 秒重试。
- 角色列表按 revision、名称和头像判断是否变化。
- 本地会话不可用返回可重试的 503，凭据无效才触发重新认证。
- 过期桌面会话自动清理，认证失败只重试一次，重复错误提示去重。

### 提醒事项

- 提醒事项改为紧凑工作台，顶部显示任务数和调度状态。
- 任务列表合并角色标签，提供独立空态、加载失败和重试。
- 支持 `/reminders?create=1` 直接打开新建任务。
- 待执行按日期与时间排列，执行历史保留周期并入工具栏。

### 记忆隐私

- 记忆新增「禁止主动提及」开关。
- 主动任务可在安全策略开启时过滤禁止主动提及的记忆。
- 普通对话仍可按原规则使用，开关不会被普通编辑重置。

### QQ 个人号与 SnowLuma

- QQ 个人号升级到 `0.2.29`，支持 Windows 原生、Linux 原生和 Docker。
- 原生模式下载 SnowLuma Lite，校验 SHA-256 后使用项目内置 Node 启动。
- 安装使用独立版本目录和原子安装指针，同版本重装不会删除当前可用版本。
- 原生 OneBot 配置只创建 Amitia 反向 WebSocket 客户端，不开放额外 HTTP/WS 服务并拒绝 3000 端口。
- Docker 模式支持启动 Docker Desktop、等待服务、启动 SnowLuma 容器和诊断权限问题。
- 页面新增连接指标、安装进度、运行模式确认、访问入口和凭据管理。

### 数据恢复与进程

- SQLite 备份改为 `VACUUM INTO` 一致性快照并执行完整性检查。
- 备份保留最近 5 份并按每日一份保留 14 天。
- SQLite 短读、I/O 错误和损坏会触发连接池恢复并记录健康统计。
- 更新安装前严格停止插件、核心和子进程，无法确认时中止安装。
- 插件关闭增加生命周期互斥、残留进程树清理和宿主归属验证。

### 桌宠、运行时与表情插件

- 桌宠首帧节流时重试发布点击蒙版，避免首帧点击区域缺失。
- Node 运行时升级到 `26.12.1`。
- 桌面数据默认保存到安装目录旁，升级时迁移既有用户资料和本地数据库。
- Windows 安装器补充提权流程和界面层级处理，减少更新与覆盖安装异常。
- Windows 内置 PowerShell 7，宿主命令使用随应用发布的运行时。
- 模型、工具和恢复阶段失败时保留结构化错误详情，重连后仍能显示具体原因。
- 表情插件升级到 `1.1.10`，新增未分组、最近使用和自定义分组栏。
- 表情列表改为紧凑贴纸网格。

## 适用范围

### 更新通道

- Windows、macOS、Linux 桌面端
- Web 客户端
- Android arm64-v8a
- 本地 Core、设备代理与云端统筹模式
- QQ 个人号插件 `0.2.29`
- 表情插件 `1.1.10`

## 升级说明

- 旧搜索 API、`web.run` / `web_run` 和网页研究引用存储不再提供。
- 升级会自动备份数据库并执行旧搜索存储退场迁移。
- BDI 配置从下一轮对话生效。
- QQ 原生模式需要用户自行准备 QQ 和系统图形运行依赖，macOS 只能使用 Docker。
- 更新桌面端前请保持 Core 运行，以便确认插件和子进程安全退出。
