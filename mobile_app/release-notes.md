更新日志

26.2.0-beta.15

## 长期任务维护修复

- 长期运行维护改为展示真实任务状态、执行位置与活动任务数量，不再读取旧会话记录判断任务运行状态。
- 全局并发设置直接应用于真实调度与任务进程，并在重启后恢复。
- 超时设置复用统一超时策略，支持禁用；保存时验证执行器回执与配置版本。
- 切换 Core、设备模式或管理员权限后拒绝旧页面操作，适用于本地、云端 Core 和设备代理。
- 修复正式 TaskHost 编译后无法正确动态加载任务入口的问题。


本次更新集中统一设备数据归属、备份恢复、通知、聊天历史与导入、持续事项、情绪与反馈、安全隐私、语音、用量和桌宠状态链路，减少模式切换、重连和跨端操作时出现的数据不一致、重复写入与假成功。

## 数据归属与跨模式

- 本地 Core、设备代理和云端统筹统一使用当前 Owner 的数据归属规则。
- 历史会话、消息和摘要保留来源与只读状态，切换 Core 或显式续接时不再混入其他 Owner 的数据。
- 旧持续事项、情绪历史、消息反馈和导入记录会在启动时自动迁移，无需手工修改数据库。
- 本版本涉及的旧安全、通知、导入、情绪、反馈、语音、持续事项和桌宠接口完成退场，正式客户端只使用当前设备、角色和权限范围对应的业务接口。

## 数据迁移、备份与恢复

- 支持“全部数据、角色及关联数据、设置与集成、记忆”四种迁移范围，以及可迁移格式和完整格式。
- 用户数据可选择口令加密导出，导出前会展示组件、记录数、预计大小和敏感或可重建标记。
- 导入包先进入隔离区完成校验、解密和冲突预检，确认后才写入，并提供保留双方、跳过或覆盖三种冲突策略。
- 导入成功前会创建恢复前备份；完整灾难恢复同样先预检，并在执行前自动创建当前设备备份。
- 完整恢复用于当前设备 Runtime 数据，完成后需要重新启动应用；Cloud 模式不会直接覆盖共享 Cloud Core 数据库。
- 电脑端和手机端均提供迁移导出、迁移导入、完整备份、恢复和配置单独导入导出。

## 跨平台通知

- 通知设备偏好、分类、静音、预览、测试通知和投递回执统一由正式通知运行时管理。
- macOS 接入通知中心，Windows 设置固定应用身份并支持通知分组，Linux 配置桌面入口、通知类别和应用图标。
- 支持消息完成、执行状态、通话、提醒和系统测试通知，并可在前台或静音场景下抑制不必要的提示。
- 首次使用系统通知时需要授予对应平台的通知权限，实际展示还取决于系统勿扰模式和应用通知设置。
- Android 与 iOS 继续使用同一套设备分类和推送链路，通知不会依赖旧聊天表推断归属。

## 聊天历史、导入与持续事项

- 会话搜索、摘要、导出、引用和工作台按当前 Owner 的统一资源读取，历史导入记录以来源标识和只读规则参与。
- 聊天清理先展示会话、消息和预计释放空间，再使用版本校验执行；默认不清理记忆，只有用户明确选择时才处理相关记忆。
- 聊天导入改为“解析预览、确认暂存、加入设备聊天”的完整流程，重复确认不会生成重复批次。
- 电脑端和手机端均会在真实写入成功后显示“已加入设备聊天”，并提供进入正式会话的入口。
- 可把升级前识别到的待晋升导入记录重新加入当前设备聊天，历史记录不会只停留在旧表中。
- 持续事项统一保存绑定、进展、用户等待项和运行事件，同一会话跨轮次复用同一事项，重启后仍可恢复。
- 定时等待、依赖事件和完成确认使用同一 Owner 链路，过期权限或模式切换不会重放未确认操作。

## 情绪、反馈与运行状态

- 当前心理状态和情绪历史分开保存；聊天可生成带阈值、置信度、恢复信息的有界情绪快照。
- 电脑端和手机端均可查看、单条删除或清空情绪历史，删除使用版本校验和持久墓碑，重启后不会复活。
- AI 回复新增“有帮助”“需要改进”和“报告不安全内容”操作，并支持已提交状态与撤销。
- 消息反馈统计、最近反馈和安全事件按当前 Owner、角色和会话隔离，不再扫描整张表或使用旧消息路由。

## 安全与隐私

- 安全策略按当前 Owner 和 revision 动态生效，支持阻断、改写和仅审计三种处理方式。
- 输入在调用模型前检查，模型输出在保存前检查；拦截事件会记录真实请求、会话、消息和处理结果。
- “报告不安全内容”会与安全事件在同一事务中提交，重复反馈不会重复生成事件。
- 安全事件支持查看、单条确认处理、清空和版本冲突保护，旧请求的重复处理不会覆盖新状态。
- 隐私扫描覆盖当前设备聊天和新导入记录，支持分页、停用角色、扫描历史与未完成状态提示。
- 手动脱敏会校验原文版本和指纹，只允许持有方执行固定脱敏，避免误改其他设备或其他会话的数据。
- 数据生命周期删除支持记忆、消息、会话和角色，存在多个来源时由用户明确选择，并展示读取阻断、清理中、完成和失败状态。
- 删除只有在持有方完成回执和存储核验后才显示完成；派生数据尚未清理时会明确提示稍后继续核验。

## 语音、关系时间与用量

- 复刻音色试听和正式朗读统一进入 Owner 语音链，并支持明确选择复刻音色。
- 多角色场景必须明确选择试听角色，不会再静默使用第一个角色；音色失效或权限变化时明确失败。
- 关系时间设置、互动次数、久别重逢、重新适应和事件历史统一按 Owner 保存，取消或失败不会伪造成功互动。
- 使用统计改为记录真实模型调用以及输入、输出和缓存 Token；供应商未返回用量时显示未知，不再填成零。
- 重置统计只推进计量起点，不删除消息、聊天记录或已有调用日志。

## 桌宠与稳定性

- 桌宠生成完成后可进入处理任务，逐个动作查看结果，并支持重试、切换尝试或排除失败动作。
- 处理完成后可生成可安装发布包，发布包含动作清单、版本、包哈希、来源信息和许可声明。
- 电脑端和手机端可直接选择已生成发布安装桌宠，也可在安装后切换版本、修复或重新安装。
- 桌宠安装、启停、默认动作、位置重置和卸载会跟踪到运行端确认，不再在等待阶段提前显示成功。
- 安装页面分别展示期望状态和实际状态，包括动作、版本、健康检查和同步进度。
- 重复操作使用幂等键，同一请求不会重复创建安装任务；运行端失败和超时会显示真实错误。
- 修复旧桌宠服务、旧操作接口和重复状态来源，电脑端与手机端现在读取同一套实际运行状态。
- 本版本涉及的旧业务接口不再提供兼容回退，相关旧客户端需要与本版本同步升级。

## 适用范围

- Windows、macOS 和 Linux 桌面端
- Web 客户端
- Android arm64-v8a 正式客户端
- 本地 Core、云端统筹 Core 与设备代理模式

- 本次升级自动执行数据与结构迁移，不需要手工重写数据库；涉及设备统筹、聊天历史、导入、备份恢复、通知、情绪、反馈、隐私、语音和桌宠的旧客户端应升级后再继续使用。
