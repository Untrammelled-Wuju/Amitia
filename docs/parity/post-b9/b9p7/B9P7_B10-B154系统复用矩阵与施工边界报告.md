## 4. Construction Mode定义
基于B9P7施工模式Schema定义的8种施工模式：

| Mode | 优先级 | 描述 |
|------|-------|------|
| REUSE | 1 | 系统已存在且为Canonical，直接使用，不修改核心架构 |
| EXTEND | 2 | 已有Canonical System，在原系统上扩展Parity缺失能力 |
| ADAPTER_ONLY | 3 | 上层合同已有，只需平台/边界适配器实现 |
| NEW_PROVIDER | 4 | 能力本身不存在但Kernel合同已有，只新增Provider实现并注册 |
| MIGRATION_ONLY | 5 | 系统已有新Canonical实现，只能把旧实现迁入 |
| INTEGRATION_ONLY | 6 | 各模块已完成，只允许接线（注册/绑定/声明） |
| VALIDATION_ONLY | 7 | 只做验收、扫描、测试，禁止修改实现代码 |
| FORBIDDEN_DUPLICATE | 8 | 原方案会建立第二套系统，必须禁止并修订为上述模式之一 |
