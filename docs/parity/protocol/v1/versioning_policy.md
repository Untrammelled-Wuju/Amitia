# Versioning Policy

## Semantic Versioning
All protocol elements follow semantic versioning: MAJOR.MINOR.PATCH

## Version Format
- **Major**: Breaking changes
- **Minor**: New features (backward compatible)
- **Patch**: Bug fixes (backward compatible)

## Baseline Versioning
- Format: PARITY-YYYY-MM-DD-VN
- Example: PARITY-2026-08-07-V1

## Protocol Versioning
- Format: PROTOCOL-V*Major*>.<Minor>.<Patch>
- Example: PROTOCOL-V1.0.0

## Deprecation Policy
1. Mark deprecated in current version
2. Remove in next major version
3. Provide migration path

## Compatibility
- Minor/Patch: Backward compatible
- Major: May contain breaking changes
