## Naming Conventions
- Use UPPER_SNAKE_CASE
- Avoid platform-specific names in capability IDs (except Provider)
- Keep IDs semantic and descriptive
- Maximum 5 segments

# Permission ID Rules

## Format
`
PERM.<DOMAIN>.<RESOURCE>.<LEVEL>
`

## Components
- **DOMAIN**: Functional area (FILE, SYSTEM, NETWORK, etc.)
- **RESOURCE**: Resource being accessed
- **LEVEL**: Access level (READ, WRITE, EXECUTE, ADMIN)

## Examples
`
PERM.FILE.WORKSPACE.READ
PERM.FILE.WORKSPACE.WRITE
PERM.SYSTEM.SETTINGS.WRITE
PERM.NETWORK.REQUEST.EXECUTE
PERM.DEVICE.CAMERA.READ
`

## Access Levels
| Level | Description |
|-------|-------------|
| READ | Read-only access |
| WRITE | Write/modify access |
| EXECUTE | Execute/invoke access |
| ADMIN | Administrative access |
