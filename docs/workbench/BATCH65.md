# U-Ai Workbench 第 65 轮：研发实现范围收口与独立生产验收

## 变更内容

- `gitworktree.Manager.Create` 统一使用仓库级分配锁和跨进程合并锁，在创建与创建失败补偿期间维持与 `EnsureTask` 一致的锁顺序。
- `Create` 在分配锁内获得合并锁后才进入 `createLocked`，保证失败恢复时调用 `removeWithMergeLock` 具有实际合并锁保护，并且不会影响 `EnsureTask` 已持锁的路径。
- 新增真实 Git 用例，确认已有合并锁会阻止并发创建，超时不会偷偷分配工作树；锁释放后创建和正常删除仍能完成；模拟 Git 已创建成功但返回失败的补偿路径仍正常回收。
- 既有终端、浏览器、Device Mesh、Coding Worker 与多端源代码继续完整保留，不删除历史功能或重置工作目录。
