# Workbench 第 6 批：浏览器控制权原子化与多端恢复

## 目标与基线

基线为 `U-Ai_Workbench_Batch05_累计完整源码包.zip`，本批只变更源码、测试及本实施记录。仍使用现有 Go BrowserProvider 与 AgentUIEvent，不另建浏览器运行时。没有对 Electron 发布产物、数据库或既有安装包进行修改。

## 服务端互斥

原先观察者的导航、回退、刷新与鼠标输入只进行控制权检查，检查后发起 BrowserProvider 调用存在租约过期或撤销的竞态窗口。现在 `BeginManualTabMutation` 在同一互斥锁下验证租约归属、有效期与 Agent 正在执行的状态，并登记正在执行的手动操作。每个观察者的 `navigate`、`action`、`input` 必须通过该入口，使用 `defer` 在调用结束时释放计数。

Agent 进入修改性操作的入口同时检测手动操作计数。即使租约在手动操作进行中到期、主动释放或者引用被撤销，后续 Agent 操作也会等待已经提交的用户操作结束。手动操作完成回调和 Agent 完成回调均保证幂等，防止异常路径重复结束而错误释放其他正在运行的操作。

该机制不改变只读观察或独立浏览器页面的权限语义；对于独立页面仍走现有会话所有权检查。Agent BrowserAgent 范围之外直接调用 BrowserProvider 的其它路径尚未接入同一协调器，故不能视为全局 Browser Runtime 操作锁。

## Web 会话状态

Workbench 现在把已处理的 `operationId` 限量保存在每个对话工作区的会话状态内。浏览器、文件、Git 等打开命令按照 `conversationId` 写入相应会话，不依赖当前正在显示哪一条对话。后台开启时不切换当前对话，不使工作区抢占前台焦点；第一次为某对话后台创建标签时仍设置该对话将来的默认选中标签，但不把该工作区设为可见。

从持久化状态恢复时过滤异常操作 ID 并限制容量为 200 条；重复事件，包括重启应用后的 SSE 重放，若 `operationId` 已出现则不重复创建标签。事件适配器使用事件所属对话 ID，并校验 ID、浏览器 URL、浏览器观察引用与视图类型。

## Flutter 浏览器生命周期

屏幕进入后台或不活动状态时，截图轮询与控制权续租停止，并尝试释放临时控制权。回到前台后按需要恢复现有会话。设备 Runtime 暂时不可用时按较低频率尝试重新连接，不持续密集轮询。切换会话、标签或浏览器引用后，旧请求通过 generation 标记避免污染新视图。

显式退出 Agent 浏览器观察时不会自动重新挂载；用户仍可点击“重新连接”。浏览器观察与用户控制仍仅通过设备本地路由调用。跨设备授权转发尚未实现，手机远程跨设备场景不能视为完成。

## 验证与后续

Go 控制权纯逻辑使用 Go 1.23.2、独立 GOPATH 模拟 Browser ID 类型的最小测试模块执行 `go test -race`；这不是项目 Go 1.26.1 的全量编译或 BrowserProvider 真实联调。Web 使用 TypeScript 转译解析、隔离的存储模型断言与事件协议断言；没有安装项目全部前端依赖，未运行正式 Vitest。Flutter 无 Dart SDK，改动只完成静态检查，未执行 `flutter analyze` / 真机测试。

后续应优先升级至指定的 Go/Flutter 工具链进行完整构建，补 BrowserProvider HTTP 层并发集成测试及正式跨设备 Device Mesh 授权转发，然后建设 Git Worktree 与交互终端。尚未达到生产级验收。
