# Workbench 第 49 轮：终端会话撤销及跨连接一致性

本轮基于第 48 轮累计源码，修复终端管理器已移除会话之后，既有请求仍持有旧 `session` 引用时可以继续尝试输入或调整大小的问题。终端关闭、任务权限撤销、空闲回收和管理器终止统一将会话设置为不可接收命令，并唤醒已连接的状态观察者。会话快照和 WebSocket 状态投影对已撤销实例不再报告 `running=true`。

输入与窗口尺寸调整现在使用相同的串行操作锁，并在进入进程调用前检查关闭标志。资源关闭仍主动调用底层 `process.Close()`，不等待可能阻塞的外部进程写入完成；已经在关闭前进入系统调用的操作以进程实际关闭行为为准，不宣称操作系统级原子取消。

新增 `session_revocation_test.go`，覆盖关闭、权限撤销、空闲回收、持有旧指针的请求、输出订阅通知和并发操作；测试引用真实 Manager、Session、Buffer 源码并启用 Go race 检测。项目研发门禁同步纳入新增测试文件。
