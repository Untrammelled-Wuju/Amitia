# Workbench 第 21 轮：任务终端与有界输出导出

本轮延续第 20 轮累计源码。变更分散在 Go terminal Runtime、服务端可信绑定适配层、Vue 工作区、VT 解析层和协议契约文件，不创建新的并行终端管理系统。

## 实现范围

- 工作区终端支持可选的 `taskId`，但任务关联只在服务端依据 Git Worktree 管理器返回的 `TaskBinding` 验证。验证同时要求工作树由本系统管理、工作树挂载 URI 一致、绑定任务和绑定对话完全一致。普通终端仍可使用，不允许客户端自称已获得 Agent 任务身份。
- 已绑定任务的终端在后续 HTTP 读取、输入、调整尺寸和导出以及 WebSocket 连接与指令传输前执行状态检查。发现绑定被解除或工作树不可用时，将拒绝该次操作并关闭原终端会话。此检查并不是分布式原子锁，也不保证在外部解除工作树关联的瞬间中断已经处于内核中的输入操作。
- `GET /api/workbench/terminal/:id/export?conversationId=...` 为**明确由用户触发**的输出导出，不会后台保存 Shell 输出到永久日志。响应记录任务 ID、工作区 URI、模式、运行状态、退出码、绝对输出游标、截断标记和 Base64 字节。只允许当前可信 UI 对话的会话持有者导出，带 `Cache-Control: no-store`，原始输出缓冲最多 256 KiB。用户下载前弹出可能含敏感内容的确认提示。导出的 Shell 输出属于可供人工核查的原始材料，不能充当可信构建证明。
- 浏览器本地工作区标签可携带 `taskId` 并跨重启恢复；Workspace Git 页面打开已绑定 Worktree 时自动填写任务 ID。服务端独立核验标签声明，避免仅修改标题就获得任务归属。未绑定会话显示独立标签提示。
- VT 解析支持 `CSI ? 2004 h/l` 的 bracketed paste 切换；粘贴时清除潜在逃逸控制字符，单帧至多 4096 字节；组合音标附在当前字符单元而不是错误占用一列。这仍是内置 VT 兼容层，并非完整 xterm.js。

## 本轮安全边界

- 不能远程从 Cloud Core 任意开启终端；继续使用已认证的本机 Workspace 和可信 Local UI。
- 不会自动把输出采集为 Agent 测试证据，也不会创建自动执行任务的工作进程。
- 不做跨设备远程 Shell 控制，不开放任意文件日志路径，不持久存储 CLI 输出。
- 撤销检查发生在 API / WebSocket 操作边界，不是独立进程间的事务锁。需要后续统一 task-runtime 信号与权限状态才能获得强实时撤销保障。

## 实际验证

- 独立 Go 终端核心测试：`go test -race -count=1 ./...` 通过，包含任务身份、过期撤销、会话隔离、输出容量、WebSocket 一次性票据。
- 变更 Go 文件的解析与格式检查通过；8 份 TypeScript/Vue 源码的脚本语法检查通过，VT 粘贴和组合字符行为断言通过。
- 终端会话、列表、输出导出与标签命令 JSON Schema 检查通过。
- `Go 1.26.1` 完整工程构建、Vue/Vitest 正式项目测试、Electron Windows ConPTY 实测与 Flutter 构建仍未在当前 Linux 容器完成，因此本轮结果不得称为生产级端到端验收。
