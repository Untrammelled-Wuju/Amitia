# U-Ai Workbench Batch 36：终端流连接生命周期恢复

本轮延续 Batch35 的累计源码，重点修复 Web/Electron 终端流在标签切换、慢速鉴权、握手停滞和断线恢复时的资源生命周期问题。不新增第二套终端 Manager，不更改已有后端终端权限规则。

## 变更

1. WebSocket 连接采用可取消的 AbortSignal；申请短期票据时传递请求取消信号和 12 秒超时。取消前、申请票据后、解析设备路由后均检查连接是否已失效。
2. WebSocket 握手增加 12 秒超时；失败时关闭失效连接、移除事件监听器、清除计时器并进入既有轮询回退路径。
3. WorkbenchTerminalView 对每次连接使用独立 AbortController；标签停用、卸载、终端关闭及重新连接时先撤销旧连接，旧请求的 finally 不得清除新请求状态。
4. 终端快照只接收当前 session ID 且包含非负安全整数游标的消息；Resize 仅发送合法整数尺寸。
5. 终端共享错误类型抽取到独立文件，支持对真实票据单次消费、有效期、容量和并发竞争进行无第三方依赖的 Go race 定向测试。
6. 新增独立 Node 测试，对实际 TS 终端流源文件进行语法转译执行，验证连接、错误游标、取消票据、取消握手、握手超时；将该测试与终端票据 race 测试纳入统一隔离门禁。
