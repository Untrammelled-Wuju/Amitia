# U-Ai Workbench 第 64 轮：Worktree 创建失败补偿与取消后清理

## 实际源码修改

- 新增创建失败补偿路径：如果 `git worktree add` 已登记工作树，但 Git 进程返回失败，或创建后核验工作树列表失败，使用保留调用上下文值但独立于调用方取消信号的五秒清理上下文重新读取 Git 状态。
- 补偿仅处理本次创建的随机 ID，必须确认为本应用管理且位于预期路径、未绑定、未锁定、未脏、没有待决合并和检查点；符合条件时调用现有的非强制删除路径。不能确认安全的情况保留资源并报告诊断，不执行递归强制删除。
- 创建期间调用方取消或超时之后，仍有机会清理已经登记成功的临时 Worktree；原始错误类型由错误包装保留。
- 新增真实 Git 故障注入测试，覆盖 Git 完成后报告失败、列表读取失败、取消发生在登记成功之后，以及出现未跟踪文件时保护现有数据。
