# Batch 45 — Browser 租约、跨设备响应与 Flutter 生命周期收口

## 工程变更

- 在已有 Browser 租约注册表中将 Agent 对同一浏览器标签的变更操作改为单写者；不同标签仍可并行。等待写权限的操作遵从取消信号，完成函数重复调用安全。
- Device Mesh 浏览器响应失败分支统一校验结构、允许的错误码和重试语义，不再透传来源设备给出的任意错误字符串；合法结果仍由原有类型专属白名单校验。
- Flutter 浏览器组件切换 Conversation、Tab、BrowserRef 或目标设备时，立即失效旧帧、旧 DOM、旧租约和待处理回调；释放控制使用原会话身份而不是新组件属性。
- 旧控制权获取请求如果在切换或退后台后才完成，使用创建请求时捕获的服务句柄释放原目标控制权；晚到响应不能清空新会话的控制状态。
- DOM 观察按请求代次限制，限制 1 MiB 字符数据，并在失活、销毁、关闭和切换后拒绝旧响应覆盖当前视图。
- 更新 Dock 生命周期测试，使断言与现有 `pause()` 代次管理一致；增加 Flutter 浏览器源代码结构门禁并接入现有定向门禁。
