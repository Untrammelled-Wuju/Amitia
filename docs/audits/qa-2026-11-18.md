# Amitia 深度测试与缺陷回归

本轮在隔离环境复现并修复四项缺陷。测试基线是 `develop` 的 `33b0292e` 加运行前已有的 259 项工作区改动，应用版本为 26.2.0-beta.22。测试以 2026-11-18 上海时间记录。隔离 Electron 实例复用 5178 上的前端源码服务，使用单独的数据、配置、凭据、工作区以及动态 Core、数据库和调试端口。Core 从源码构建三次用于逐项回归，随后用包含 SQL 修复的 Core 创建全新库。Electron 主进程与 preload 使用本机已编译的开发构建。共享开发服务在测试期间另行重启，末次实测 Vite HTTP 200、Core 7 项就绪。系统为 macOS arm64，使用 Go 1.26.1、项目 Node 26.12.1、Flutter 3.47.7。

## 风险与未覆盖

- 三个聊天清理测试期望允许无条件或空结果确认，当前实现明确拒绝两种请求。保留原断言。带真实数据的接口确认、备份和 SQLite 验证已完成；共享开发服务重启后，真实页面复跑无条件预览也显示拒绝。完整页面清理未验证。
- 运行统计同屏出现全角色会话为 2、数据概览会话为 0。源码和接口表明后者聚合统筹中心数据所有者，两条聊天会话由设备持有。随后按 API 再查，中心会话与全部归属会话为 1 和 3。页面对这两个范围的解释仍不清楚。
- 移动聊天的消息保护静态断言、Web 聊天的失败状态断言仍需客户端行为复核。没有 Android 连接，主机缺少 iOS 模拟器工具。Windows、Linux、Android、iOS 的 GUI 和发布安装均未验证。
- 独立云端部署、设备实配和离线重连、外部 Web 登录及已认证业务、真实模型输出质量、实时通话、ASR/TTS、外部消息渠道、第三方 MCP/OAuth 和市场外部链路未覆盖。
- 桌宠碰撞或多窗批量停用、主机升级、桌宠更新和欠确认恢复，工作区终端执行和文件写入、长任务取消、通知跨端送达、导入全链路、知识检索与图谱质量、游戏运行、自动更新安装缺少真实端到端证据。管理端仅登记源码入口。
- 测试使用业务夹具与环回 HTTP 模型，模型端是预设响应。浏览器 DOM、Electron、Core、SQLite、Qdrant、SurrealDB、MCP 子进程和桌宠包安装均真实运行。单元或源码断言、接口合同检查、页面入口和完整业务结论采用各自的证据范围。
