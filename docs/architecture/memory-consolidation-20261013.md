# 记忆主链整合

## 本次边界

复用现有设备归属业务引擎与当前界面。手机保留记忆管理、情景记忆、记忆图谱、记忆时间线、用户画像、世界书六入口及三行两列布局。电脑使用同一读写、候选审核和分区契约。

不迁移或读取旧版本记忆、画像、情景和图谱数据，不提供旧格式转换或旧记忆分区迁移。当前系统生成的数据在设备切换后仍可按原设备授权查看，这不属于旧版本数据兼容。聊天记录、角色、配置和运行数据没有执行物理清理。

源码开发阶段按用户要求只完成源码与测试。用户随后授权构建并安装 Android Release APK，并将现有源码变更一起纳入本地发布基线；不推送 Git，不上传安装包。构建与真机结果以发布记录为准。

## 业务结构

- `kernel_device_owned_resources` 的 `memory` 是原始记忆资源；画像、情景、事实、向量、图谱保留来源引用。
- `business.Engine` 负责数据归属、候选审核、冲突处理、版本校验、提交确认与失败重试。
- 生命周期算法统一在 `memorypolicy`。既有记忆类型库通过同一算法计算等级和强度，不复制另一份算法。
- 手机及网页新增、查询、候选操作接入 `/api/device-mesh/v1/business/memories*` 和 `memory-candidates*`；正文与生命周期修改使用原资源的版本及执行范围。
- 本机聊天后处理通过 `ObserveMemory` 复用同一增量生成及提交流程；实际召回的原记录版本随后处理事件保存，避免强化未召回或已变化的记录。
- 反思与聊天记录导入候选进入同一审核账本。导入提取失败返回错误，不再把原消息当成已成功提取或已保存的记忆。
- 插件记忆查询改为当前业务引擎查询。缺少数据归属时拒绝，不读取旧记忆表。
- 当前对话将世界书规则加入模型上下文。
- 首次引导的初始记忆通过同一主链保存为画像资源，失败时不显示完成；仪表盘使用统一接口返回的实际总数。

## 生命周期

L1 保持强度 1；L2—L5 默认强度分别为 0.86、0.68、0.50、0.36，半衰期分别为 365、90、30、7 天。沿用已有类型、子类型和重要度分级规则。

时间衰减按原强度更新时间计算，不因刷新页面重置。强度下降可导致等级下调、淡化或自动归档。退出有效召回的原始记忆同时阻断依赖的向量与图谱使用。

固定操作设置 L1 和完整强度、恢复活跃并取消手动归档；停用和明确到期限制仍独立生效。对话使用后的强化纳入原有提交账本，重试同一请求不会重复强化。

界面支持等级、强度和固定设置，以及等级、固定和衰减状态筛选。模型自动提取结果不能直接设置固定或覆盖生命周期字段。

## 删除和收敛

删除手机被门禁遮住的第二套页面内容，保留原路由组件作为当前页面的薄入口。角色记忆和角色时间线同样复用当前页面。

删除电脑端五个旧记忆页面、孤立的旧编辑器、列表、候选、检索和诊断界面，以及旧接口客户端。聊天侧面板只使用当前记忆组件，服务故障时明确提示。

删除旧记忆读取分页、旧图谱转换和旧数据分区迁移的运行链路及相应接口。旧版本兼容测试改为验证旧数据不会进入当前读取或画布。

手机 `MemoryService` 收敛为当前主链的只读数据适配，用于聊天预览等现有调用；删除未写入就返回记录、常量评分、返回 false 的批量修改等遗留实现。

既有数据库声明式基线及已发布迁移没有改写；本次新增字段存放在现有资源 JSON 内。

## 验证边界

定向验证包含生命周期、CAS、筛选、分页、同一请求强化幂等、观察后处理、反思候选、原设备数据隔离、实际 TLS 记忆接口、导入 HTTP 确认、手机页面布局及两端控件接入。

网页定向测试 53 项通过，包含六入口、版本校验、候选审核、引导初始记忆保存失败及幂等重试。手机定向测试 37 项通过，包含三行两列布局、窄屏和大字体、来源隔离与服务错误状态。

后端生命周期、业务引擎、实际 TLS 记忆接口、HTTP 导入候选确认及聊天上下文定向测试通过。新增验证重复读取不会重复衰减、模型输出不得直接固定记忆、历史快照中的旧记忆集合不会进入当前聊天提示。

网页类型检查使用项目 Node 二进制。全局检查有六条既有错误，来自两个渠道布局测试缺少 Node 类型声明；本次修改没有新增类型错误，不能将全局检查计为通过。扩大执行引导测试时，已有路由源码断言仍要求旧式 `next` 返回写法，与现有路由实现不符，本次没有修改路由或该断言。

早期扩大到业务包的测试发现项目和摘要范围校验失败；本次没有修改其业务实现，最终验收采用直接涉及记忆的定向测试，不能据此声称整个业务包全部通过。

手机静态检查区分错误、警告与既有信息级提示。界面测试不代替 APK 构建、真机安装或完整服务健康验证。

本次手机定向静态检查无错误、无警告，有 49 条信息级提示。源码差异检查通过。既有底层类型库、数据库基线和隐私、备份等通用基础设施尚有旧表定义与类型引用，它们不作为本次记忆管理、聊天生成、导入和查询的运行主链；本次没有宣称全项目物理删除所有旧表或基础类型。
