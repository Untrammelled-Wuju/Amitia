# Android 普通返回与 320ms 页面转场

版本：26.2.0-beta.16，versionCode 22。

## 更新内容

- 关闭 Android 预测返回预览，移除页面转场对系统预测手势进度的接管。
- 系统滑动返回确认后执行普通页面返回；系统返回键和页面内返回按钮保持可用。
- 页面进入与返回时长统一为 320ms，保留缓入缓出曲线与上下层页面等距联动。
- 保留 iOS/macOS 的应用内边缘拖动返回。

## 验证与构建范围

源码变更仅涉及手机端转场、Android 应用清单和对应测试。运行导航及转场定向测试、变更文件静态分析，验证系统预测事件不被接管、普通返回在 320ms 内完成、逐帧页面边缘贴合。

正式 APK 从同一源码基线重新构建 Linux ARM64 后端、plugin-host、task-host 及 Runtime Package，完成 Release lint、无障碍 lint、assembleRelease、正式签名匹配、16KB 对齐、单 arm64 ABI、内嵌 Runtime 和源码提交校验后覆盖安装到真机。保持当前版本，仅本地构建和安装，未发布更新通道，未推送 Git。
