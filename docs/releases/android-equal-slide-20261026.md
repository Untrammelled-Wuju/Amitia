# Android 页面同步转场修复

版本：26.2.0-beta.16，versionCode 22。

## 更新内容

- 页面进入与返回改用等距推移，上下层页面边缘始终贴合，消除原 30% 视差位移造成的遮挡。
- 普通进入动画调整为 420ms，返回调整为 380ms，使用对称缓入缓出曲线。
- 预测返回与边缘拖动直接跟随手势进度，停手时页面保持当前位置，松手后平滑完成或回弹，收尾时长为 220–380ms。
- 系统返回按钮使用普通返回动画，避免重复触发预测手势。
- 统一现有业务页面的横向路由入口，保留全屏模态页面原有语义，底部入口切换保持即时响应。
- 随本地源码基线保留现有手机页面路由迁移及发布就绪报告更新。

## 适用范围

Android 正式版手机端；本次仅本地构建及安装，不发布更新通道，不推送 Git。

## 验证计划

对进入、返回、多级页面、预测返回完成与取消进行逐帧边界验证；检查拖动暂停和收尾时长。运行导航与 UI 路由模块定向测试及变更文件静态分析。从同一源码基线重新编译 Linux ARM64 后端、plugin-host、task-host 并生成新的 Runtime Package，再执行 Release lint、正式构建、签名和内嵌 Runtime 校验，覆盖安装到已连接真机，验证冷启动与页面转场。
