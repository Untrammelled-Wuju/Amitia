|---|---|---|---|
| REG-B-001 | B-01 | 单轮文本、图片、语音转文本各发送一次 | 当前用户消息在模型上下文和记忆流水线中各出现一次 |

## 风险回归用例

| 用例 | 覆盖 | 输入 | 断言 |
|---|---|---|---|
| REG-R-001 | R-01 | 多个心理模块同时产生增量 | 总变化受预算限制 |
| REG-R-002 | R-02 | 模糊用户陈述 | 不写确定事实，保留低置信候选 |
| REG-R-003 | R-03 | 证据不足的长期规律 | 反思不生成永久结论 |
| REG-R-004 | R-04 | 并发、乱序、迟到事件 | state_version 单调，旧事件不覆盖新状态 |
| REG-R-005 | R-05 | 主动消息与用户实时消息碰撞 | 旧输出被取消或合并，不重复发送 |
| REG-R-006 | R-06 | Prompt 规则互相冲突且上下文超长 | Prompt IR 按优先级裁剪，硬规则保留 |
| REG-R-007 | R-07 | 队列拥塞和深度路径请求 | P0/P1 优先，深度任务受预算控制 |
| REG-R-008 | R-08 | 关闭高级心理开关或依赖故障 | 基础聊天仍可工作 |
| REG-R-009 | R-09 | 多角色同词记忆和关系状态 | 检索、写入、输出均按 scope 隔离 |
| REG-R-010 | R-10 | 极端人格配置和危险边界输入 | Safety Governor 裁剪后输出安全 |
| REG-R-011 | R-11 | 连续短消息快速发送 | 旧交互不能提交过期回复 |
| REG-R-012 | R-12 | 后台任务洪峰 | 背压生效，实时聊天不被饿死 |
| REG-R-013 | R-13 | SQLite 更新后 Qdrant/SurrealDB 失败 | Outbox 重试后最终一致 |
| REG-R-014 | R-14 | 启动、停止、重启中断 | 无永久 PROCESSING、僵尸租约和半提交 |
| REG-R-015 | R-15 | 上游取消后模型或工具迟到返回 | 迟到结果丢弃且不写事实 |
| REG-R-016 | R-16 | Qdrant、SurrealDB、模型 API 连续失败 | 熔断打开，半开探测恢复 |
| REG-R-017 | R-17 | 渠道投递 UNKNOWN 后重试 | delivery_id 稳定，用户不收到重复消息 |
| REG-R-018 | R-18 | 工具调用超时但外部可能成功 | 状态为 UNKNOWN，等待补偿确认 |
| REG-R-019 | R-19 | 删除记忆后立即检索和主动消息 | 墓碑阻断所有读取和派生索引使用 |
| REG-R-020 | R-20 | 长期运行制造孤儿任务和断层版本 | 巡检服务发现、报告并补偿 |
