关键修复总结

修复项：PrimaryGlassButton 在浅色主题下几乎不可见
原因：原实现使用 Brush.radialGradient(radius = Float.MAX_VALUE)，导致渐变极度分散，仅第一个颜色（alpha=0.12白色）覆盖大部分按钮区域
方案：改为 Box + drawBehind，使用 pColor.copy(alpha=0.60f) 作为基础色（对应 HTML 的 rgba(96,119,106,.60)），叠加3层径向渐变高光（对应 HTML 的3个 radial-gradient），添加顶部内描边线和 shadow 投影
验证：8个页面的按钮均清晰可见，灰绿色填充配白色文字，与 HTML 一致
